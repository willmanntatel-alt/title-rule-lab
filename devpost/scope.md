# Title Rule Lab

A proposed local browser tool for checking a multilingual title against a rule entered by its reviewer.

## The Unique Kernel
Show the same unchanged title as code points, UTF-16 units, UTF-8 bytes and displayed character clusters. Selecting a measurement rule changes the result; the app exposes that difference instead of assuming a marketplace's definition of a character. Overflow is marked at a whole displayed-character boundary, so combining marks and emoji families stay intact visually.

## Who It's For
A listing editor working with multilingual text who has a real published field limit to check. No user study or platform integration is claimed.

## The Core Loop
Paste a title, enter a numerical limit and measurement unit, inspect counts and overflow, edit the title yourself, then export a JSON review record containing the unchanged title, counts, selected rule and optional rule reference.

## Inspiration & Identity
Agent-proposed direction: a calm editorial workbench, cream paper, ink text and orange accents. No other contestants' work is used as a reference.

## Why This Matters to the Learner
Not established. This project is an agent proposal under the user's instruction to select and complete a new task; it is not represented as a learner-authored product idea.

## What "Working" Looks Like
A demonstration shows an emoji-containing title within a code-point rule but over a UTF-16 rule, a Thai title's differing grapheme count, correction by direct editing, and a JSON review output. Numerical examples are demonstration rules, not marketplace limits.

## The POC Boundary
One browser surface, local processing, four counts, user-defined rule, visible overflow, two small demo inputs, optional source note and JSON export.

## Later
Importing validated platform policies or reviewing batches may be useful later.

## Explicitly Cut
Automatic rewriting, translation, platform compliance claims, remote storage and accounts: each adds scope without proving the measurement difference. No sales or approval improvement is promised.
